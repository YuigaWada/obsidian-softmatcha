# SoftMatcha Search

英語・日本語のMarkdownノートを検索します。モデルなしでファイル名と本文の文字列一致を検索でき、任意のモデルパックを追加するとSoftMatcha 2による意味検索も使えます。

[English](README.md) · [開発](docs/DEVELOPMENT.md) · [ディレクトリ構成](docs/DIRECTORY_STRUCTURE.md) · [公開手順](docs/RELEASING.md)

## 主な機能

- 英語・日本語の検索とUI。UI言語はObsidianに追従、または設定で固定。
- 置換された語を含む、実際に一致した原文だけをハイライト。
- 抜粋から空行・空白だけの行を省略。原文や移動先の行番号は変えません。
- ノートを開く、新規タブで開く、現在のエディターへMarkdownリンクを挿入。
- 起動時のバックグラウンド準備と、端末内の索引キャッシュ。
- 英語・日本語の意味検索を個別にオフにできます。無効なモデルは読み込みません。両方オフでも文字列一致は使えます。

## インストールと操作

公式ディレクトリで承認・掲載された後は、コミュニティプラグインから **SoftMatcha Search** を探します。リポジトリやリリースの公開だけでは掲載完了にはなりません。

手動導入する場合は、[リリース](https://github.com/YuigaWada/SoftMatcha-for-Obsidian/releases)の `main.js`・`manifest.json`・`styles.css` を `<vault設定ディレクトリ>/plugins/softmatcha-search/` に置いて有効にしてください。既定の設定ディレクトリは `.obsidian` です。モデルなしの導入でも検索できます。

コマンドパレットの **SoftMatcha Search: 検索** またはリボンの検索アイコンで開きます。ショートカットは設定のHotkeysから割り当ててください。推奨はMacが⌘⇧O、その他がCtrl+Shift+Oです。既存の割り当てと競合しないよう、自動設定はしません。

↑↓で選択、Enterで開く、⌘/Ctrl+Enterで新しいタブ、Alt+Enterでリンク挿入です。検索でノートを変更することはありません。リンク挿入だけは利用者が選択したときに行います。

## 任意の意味検索モデル

1. プラグインと同じリリースの `models-ja-<version>.zip` または `models-en-<version>.zip` を取得します。
2. 設定の **モデルパックを取り込む** でZIPを選びます。
3. **日本語の意味検索**・**英語の意味検索** を必要に応じて切り替えます。

自動ダウンロードはしません。ZIPはデータのみで、ファイル名・サイズ・SHA-256を検証してからプラグイン自身のフォルダーへ保存します。コードの追加・自己更新は行いません。モデルパックは各端末で取り込んでください。同期サービスが追加ファイルも転送するとは限りません。

日英それぞれfastTextの上位5万語を使用します。両モデルと日本語辞書の展開後サイズは約135MiBです。RAMにも余裕が必要で、大きなvaultの初回索引構築は1分以上かかる場合があります。次回以降はキャッシュから復元しますが、モデルと辞書のメモリ展開は再度必要です。

日本語文字を含む検索語は日本語モデル、それ以外は英語モデルへ振り分けます。翻訳を介した日英横断検索は提供しません。未登録語・モデル未導入・混在クエリでも文字列一致は検索できます。意味検索は12トークン以内で、候補数と実行時間に上限があります。PDF/OCR、Omnisearch検索構文の完全互換はありません。

## 対応とデータの扱い

Obsidian 1.8.7以降向けです。macOS / Obsidian 1.15.0で検索・設定画面を確認済み。iOS・Android・Windows・LinuxのObsidian実機は未検証です。CIのデスクトップOS試験はアプリ実機試験とは異なります。モバイルでは文字列一致のみ、または片言語のモデルを選ぶとメモリを抑えられます。

端末内検索は通信せず、ノートをアップロードしません。テレメトリ・広告・必須アカウント・料金はありません。モデルの手動取得先はGitHub Releases、モデルを作る開発用スクリプトの取得先はfastText公式配布です。

索引にはノート本文と位置情報が含まれ、アプリのIndexedDBに保存されます。モデル・設定はプラグインの設定フォルダーに保存されます。索引の削除やOSによる破棄後は再構築します。モデル取り込みで明示的に選んだZIPを除き、vault外を読み取ったりファイルシステムを走査したりしません。[プライバシーの詳細](docs/PRIVACY.md)
