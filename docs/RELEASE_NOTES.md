# SoftMatcha Search 0.3.0

- Standard three-file installation works immediately with filename/body search.
- Optional, manually imported English/Japanese semantic model data packs.
- Per-language opt-out, automatic/manual UI language, and local index caching.
- Compact excerpts and Unicode-safe inline highlighting.
- Full license notices, checked release metadata, and draft-release automation.

Download the three plugin files, or the small plugin ZIP. Models are separate:
import `models-ja-0.3.0.zip` and/or `models-en-0.3.0.zip` in plugin settings.
No model is downloaded automatically. Assign a hotkey in Obsidian settings.

Tested manually on macOS / Obsidian 1.15.0. Mobile Obsidian remains unverified.
Search runs locally and does not upload notes. No server setup is needed.
